# Asadullah Dal - Portfolio Website

This is my personal portfolio website showcasing my work as a Computer Vision Developer & AI Educator.

🌐 **Live Site:** [https://asadullah-dal17.github.io/asadullahdal/](https://asadullah-dal17.github.io/asadullahdal/)

## About

A modern, responsive portfolio website built with HTML, CSS, and JavaScript. The site features:

- **About Me** - My background and experience in computer vision
- **Technical Skills** - OpenCV, MediaPipe, YOLO, TensorFlow, and more
- **Featured Projects** - Showcase of computer vision projects
- **Free Courses** - Links to my YouTube tutorials and courses
- **Services** - Freelance computer vision development services
- **Contact** - Ways to get in touch

## Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with glassmorphism effects
- **JavaScript** - Interactive features and animations
- **Font Awesome** - Icons
- **Google Fonts** - Poppins, Inter, and JetBrains Mono

- ✨ Modern, polished design with glassmorphism effects
